# DigiNode Tools licence FAQ

DigiNode Tools is licensed under the [PolyForm Perimeter License 1.0.0](../LICENCE.md). This FAQ explains it in plain English. If anything here differs from the licence, the licence is what counts.

## Why is the code public?

So that anyone can see exactly what DigiNode Tools does on their computer. DigiNode Tools runs with full access to your system and looks after your DigiByte node, so you should be able to check what it does. The code is public for transparency, not so it can be reused to make other products.

## Is DigiNode Tools open source?

Not in the strict sense. It's "source available": the code is public and free to use, but the licence doesn't allow it to be used to make a competing product. Open source licences don't allow that kind of restriction.

## Can I use DigiNode Tools?

Yes, for free and for any purpose - at home, for a business, a mining pool, a school or a nonprofit.

## Can I change the code?

Yes, for your own use. You can also share your changes with me: contributions are welcome, by pull request or by opening an issue on GitHub.

## Can I make my own version of DigiNode Tools?

Not one that competes with DigiNode Tools. The licence doesn't allow you to provide others with any product that is a substitute for DigiNode Tools - whether it's free or paid, a script, an app, a website or a service, and in any programming language. This keeps one official DigiNode Tools that everyone can trust.

## Can I use the code to make a version for another blockchain?

No. A node setup or management tool for another blockchain (for example Bitcoin, Litecoin or Dogecoin) based on DigiNode Tools competes with it - the licence says a product competes "even if it is ported to a different platform". DigiNode Tools itself is planned to support other blockchains.

## Can I sell DigiNode Tools, or hardware or services that include it?

Please talk to me first. Selling DigiNode Tools, cloud-hosted DigiNodes, plug-and-play DigiNode hardware, or paid support for DigiNode Tools may count as competing. Contact: olly@diginode.tools

## Can I use the DigiNode Tools name and logo?

Yes, to link to DigiNode Tools or to write about it (articles, reviews, tutorials, videos and posts), without asking. For anything else, please ask first. See [TRADEMARKS.md](../TRADEMARKS.md).
